An AI voice receptionist that books HVAC appointments.

A voice agent that answers customer calls, understands the service request, checks live availability and books the appointment, built with Vapi, n8n and Google Calendar.

What it does

For a home service business, a missed call is often a missed job. This receptionist picks up incoming calls and handles the conversation from start to finish:

  • Understands why the customer is calling
  • Collects the customer's details
  • Checks real-time availability
  • Automatically books eligible appointments

How it works

Vapi runs the voice conversation. When the caller is ready to book, it sends the request to n8n through a webhook. n8n pulls the day's events from Google Calendar, applies the scheduling rules in a code step, and an IF step decides whether the slot is free. If it is, the event is created and the confirmation goes back to the caller. If not, the agent gets a response it can use to offer another time.

Scheduling logic

The scheduling is built around a three-technician team and covers:

  • Business-hour rules
  • Appointment capacity checks
  • A final availability re-check right before booking, to help prevent scheduling conflicts

Not every call is the same

The receptionist handles urgent service requests, installation enquiries and customers who ask for a human, and sends each one through the right workflow instead of treating every call the same way.

This is a demo build for a sample HVAC business, ComfortAir Heating & Cooling. Tools: Vapi · n8n · Google Calendar · Webhooks · API integration.
